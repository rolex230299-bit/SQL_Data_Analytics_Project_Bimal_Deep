# SQL_Data_Analytics_Project
A structured, end-to-end SQL analytics project that moves from foundational Exploratory Data Analysis (EDA) to Advanced Analytics, following a clear analytical roadmap. This project demonstrates the ability to explore, question, and extract actionable insights from raw relational data using pure SQL.
